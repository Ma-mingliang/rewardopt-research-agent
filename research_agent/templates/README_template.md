## Convention: RA_CHECKPOINT_DIR

The optimizer framework sets the `RA_CHECKPOINT_DIR` environment variable before
running `train.py`. Your training script **must** save the best model to:

```
{RA_CHECKPOINT_DIR}/best_model.zip
```

The framework provides `BestModelCallback` in the template, which handles this
automatically based on 10-episode average reward.

## Fair Evaluation

All candidate models are evaluated using the **baseline reward function** (not
the modified reward). This ensures fair comparison:

1. Baseline: train → save best model → evaluate 30 episodes → baseline performance
2. Candidate: train with modified reward → evaluate 30 episodes with **baseline reward**
3. Compare: candidate performance vs baseline performance

## Accept/Reject Decision

The optimizer uses a weighted composite score:

```
composite = Σ(weight_i × normalized_metric_i)
final_score = 0.8 × composite + 0.2 × llm_score
```

- If any hard threshold is violated → REJECT
- If final_score > composite_threshold → ACCEPT
- LLM dynamic judgment contributes 20% (falls back to 100% static if API unavailable)
